4. Stored Procedures / Atomic PL/pgSQL Functions

1. praqen_credit_deposit(user_id, currency, amount, onchain_balance, idempotency_key, note)

Performs atomic deposit crediting: writes transaction ledger entry, increments wallet balance, synchronizes mirrors, advances on-chain checkpoint, and writes audit log inside a single ACID transaction.

2. praqen_internal_transfer(sender_id, recipient_id, currency, amount, idempotency_key, note)

Performs deadlock-free atomic user-to-user transfers. Sorts user IDs prior to row-locking, verifies sender balance, updates both wallets, and writes dual ledger entries simultaneously.

3. praqen_release_escrow & praqen_refund_escrow

Manages atomic escrow release to buyers and dispute refunds to sellers without exposure to concurrency races.
